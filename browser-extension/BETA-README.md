# LesRats — Extension navigateur (Beta)

Cette extension permet d'importer des produits AliExpress / Printables vers ton compte LesRats, et de remplir automatiquement les fiches Etsy.

Tu es en beta privée. Merci de tester et de remonter ce qui marche / ne marche pas.

---

## Installation (5 minutes)

L'extension n'est pas encore sur le Chrome Web Store. Tu vas l'installer en mode "non empaquetée".

### 1. Dézippe le fichier

Choisis un emplacement **stable** sur ton disque (ex: `C:\LesRats\extension\` ou `~/LesRats/extension/`).

⚠️ **Important** : ne supprime / déplace pas ce dossier après installation, sinon l'extension cesse de fonctionner. Chrome lit les fichiers directement depuis cet emplacement.

### 2. Ouvre la page des extensions

- **Chrome** : `chrome://extensions/`
- **Edge** : `edge://extensions/`
- **Brave** : `brave://extensions/`
- **Opera** : `opera://extensions`

(Tape l'URL dans la barre d'adresse.)

### 3. Active le mode développeur

Toggle **"Mode développeur"** en haut à droite de la page.

### 4. Charge l'extension

Clique **"Charger l'extension non empaquetée"** → sélectionne le dossier dézippé.

Une icône orange "R" apparaît dans la barre d'outils.

### 5. Épingle-la (recommandé)

Clique l'icône puzzle 🧩 → trouve "LesRats" → clique l'épingle pour la garder visible.

---

## Connexion à ton compte LesRats

1. Connecte-toi sur le site LesRats avec ton compte beta
2. Va dans **Profil** → **Connecter l'extension**
3. Clique sur l'extension dans ta barre d'outils
4. Elle se connecte automatiquement

---

## Utilisation

### Importer un produit AliExpress
1. Va sur la page d'un produit AliExpress (ex: `https://fr.aliexpress.com/item/...`)
2. Clique l'icône extension OU utilise le raccourci `Alt+Shift+I`
3. Choisis la boutique de destination → import

### Importer un modèle Printables
Pareil sur `https://www.printables.com/model/...`

### Publier sur Etsy
1. Édite ton produit dans LesRats (titre, images, prix...)
2. Clique **Publier sur Etsy**
3. L'extension ouvre Etsy et remplit le formulaire automatiquement
4. Vérifie + clique "Publier"

---

## Le bandeau "Désactivez les extensions en mode développeur"

Chrome l'affiche à chaque démarrage tant que tu es en mode dev. **C'est normal**, c'est juste un avertissement. Clique "X" pour le fermer.

Il disparaîtra quand l'extension sera sur le Chrome Web Store (prévu après la beta).

## Mises à jour

Pendant la beta, tu recevras les mises à jour manuellement :
1. Je t'envoie un nouveau zip
2. Tu dézippes par-dessus l'ancien (remplace les fichiers)
3. Dans `chrome://extensions/`, clique le bouton recharger 🔄 sur la tuile LesRats
