# Icônes de l'extension

Pour générer les icônes PNG:

1. Ouvrez `generate-icons.html` dans votre navigateur
2. Faites un clic droit sur chaque canvas
3. Sélectionnez "Enregistrer l'image sous..."
4. Sauvegardez avec les noms: icon16.png, icon32.png, icon48.png, icon128.png

Ou utilisez les icônes placeholder ci-dessous (copier/coller en base64).
